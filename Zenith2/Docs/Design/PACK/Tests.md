# PACK design: tests

This file is part of the PACK design family; the entry document is `Zenith2/Docs/Design/PACK.md`. It lists every PACK test with the case it asserts, the target it builds into, the fixtures it generates and the gate step that runs it. Test names follow `Zenith2/Docs/Contracts.md → "Tests and code hygiene gates"` (doctest `"<Library>/<Type>/<Behaviour>"`, ID `Test_<Type>_<Behaviour>`); every name below is unique across Zenith2.
