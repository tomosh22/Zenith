# SAVE design — tests

This file is part of the SAVE design family. The entry document is `Zenith2/Docs/Design/SAVE.md`. It lists every SAVE test target and every named test with the case it asserts, and the gate step that runs each group. Tests follow `Zenith2/Docs/Contracts.md` → "Tests and code hygiene gates": doctest, one CTest test per case, pass or fail only, no pinned counts; tests land in the ticket that lands the code.

## Scope of this file

- Targets and source locations.
- Every named test, grouped: formats, journal and power loss, snapshot and restore, migration, the save system, replays, runtime integration, cross-system failure, platform storage, fuzzing, death tests, benchmarks.
- Which gate step runs each group.

Every binary a test loads is generated at test time (this programme's binary-artefact ruling): save files by the fixture generator or by the production writer, replay logs by recording a run inside the test; the only committed binaries are the Stage 6 shipped-build recordings (`Zenith2/Docs/Design/SAVE/Formats.md` → "Frozen fixture writers"). No test uses a test double of a final class: `Zenith_SaveSystem`, `Zenith_ReplayLogWriter` and the rest run as themselves; the seams are the interfaces `Zenith_SaveStorage`, `Zenith_SaveParticipant`, `Zenith_SaveWorldHooks`, `Zenith_SaveCompletionSink` and `Zenith_ReplaySink`.
