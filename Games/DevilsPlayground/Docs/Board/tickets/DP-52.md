## Goal
MVPScope §2.3 and Post-MVP backlog #8: *"Console platform layers (Switch / Xbox / PlayStation)"*; `Shortfalls.md` §3.7 (performance not validated for console targets) and §3.9 (no console platform layer). The engine has Windows and Android layers (`Zenith/Windows`, `Zenith/Android`) behind the `Project_*` hooks and a Vulkan-plus-Null backend model; a console needs a platform layer, a backend (D3D12 for Xbox is the reserved no-op today), SDK access and NDAs. This ticket is the survey: which target first, what the engine layers must grow (windowing, input, save, packaging), and a cost estimate against the SDK terms, recorded as a design note under `Docs/`. Implementation is filed only after a ruling. `deferred`.
