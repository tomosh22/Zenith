## Goal
`Roadmap.md` S9: *"Towns 3-6, Routes 2-8, Gyms 2-4, interiors (content = `ZM_WorldSpec` rows + recipes, not bespoke code)"*, the PURE half. Append every S9 scene to the compiled world table and prove its integrity headless, so the region waves (ZM-84 to ZM-87) author against rows that already exist and are already checked, the way ZM-D-196 found Route 1 and Thornacre already were.

GDD §2.2 fixes the indices: Cinderfell 4, Tidegate 5, Gearspring 6, Milldown 7 (traversal stub in S9), Skyshear 8 (arrival stub); Routes 2-8 at 21-27; Gyms 2-4 interiors at 43-45; Care Center 52 and Trade Post 53 as shared templates (ZM-75 decides how a template row expresses its per-town return). Scope:
- `Source/Data/ZM_WorldSpec.{h,cpp}`: `ZM_SCENE_ID` rows APPENDED before `ZM_SCENE_COUNT` (save-stable, never reordered), each with name, build index, kind, terrain-set name, connections (`ZM_SceneConnection {scene, tag}`), spawn tags and, for routes, an encounter array left for ZM-32 to fill plus a per-route named rate constant (never the shared `uZM_DEFAULT_ROUTE_ENCOUNTER_RATE`, ZM-D-196 ruling 4 trap).
- `Source/World/ZM_SceneRegistry.h`: NO registration rows yet. A registered scene with no `.zscen` on disk is a black screen (`IsWarpDestinationValid` consults the world table only, ZM-D-196 ruling 2); each wave adds its rows when it commits the files. Extend `Tests/ZM_Tests_SceneRegistry.cpp` so the "declared but unregistered" set is asserted by NAME, and the black-screen hazard has a unit that reds if a connection targets an unregistered scene at boot.
- `Tests/ZM_Tests_WorldSpec.cpp`: every warp resolves, every spawn tag the connections ask for is offered by the target, every scene is reachable from FrontEnd, build indices are unique and match GDD §2.2, kinds match, and every ROUTE row has a rate `> 0` and a non-shared constant.
- `Components/ZM_BattleTransition.cpp`'s id-tagged biome table gains a row per new scene (`ZM_BATTLE_BIOME_*`: Cinderfell/Route 2-3 VOLCANIC, Route 4/Tidegate COAST, Route 5-7 WETLAND or MEADOW, Route 8 MEADOW per GDD §2.2), with `BiomeForScene`'s self-check covering them.

No scene bytes, no terrain recipes, no trainers: those are the waves, ZM-76 and ZM-32.
