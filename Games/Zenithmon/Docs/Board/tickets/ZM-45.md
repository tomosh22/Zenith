## Goal
`Roadmap.md` S12: *"Perf pass (grass counts vs 2M cap, load times, suite runtime <= budget)"*; `TestPlan.md` §6 budgets: the headless batch in single-digit minutes at end state, slowest-10 reviewed at every gate, single-mechanic tests under 900 frames.

Measure first, then fix what the measurement names:
- **Grass:** per-scene `Flux_GrassImpl` instance counts on every outdoor scene against the 2M cap, read through the engine's counters from an automated pass over all 26 outdoor scenes; the S9/S10 gates' per-scene instance-count assertions (MasterPlan risk 4) become a table the unit reads.
- **Load times:** wall time from warp trigger to `ZM_WARP_TRANSITION` complete for every edge in the traversal plan (ZM-74 already walks them; add the timing PROBE), plus cold boot to FrontEnd, on both `Vulkan_` and `Null_` builds; a budget per edge kind recorded in `Docs/TestPlan.md` §6.
- **Suite runtime:** the headless batch, the windowed gate set and the slowest-10, from the runner's own report; anything over budget is split, seeded down or demoted to `--filter`-only with the reason in the test file.
- **Memory:** peak working set on the largest scene, recorded (no budget exists yet; this ticket proposes one from the measurement).

Fixes are ordinary engineering under the existing gates. Anything engine-side (`Zenith/**`) triggers the gate union and the cross-game sweep. The report artefact lives under `Build/artifacts/` and its summary in `Docs/Status.md` beside the S12 gate.
