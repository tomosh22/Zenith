## Goal
`Roadmap.md` S11: *"Battle Tower (interior scene + streak/rental logic + AI escalation, boss every 7th)"*. The LOGIC shipped in S2 box 6 (`Source/Battle/ZM_BattleTower.{h,cpp}`: L50 clamp, 3-member squads, boss every 7th, tier escalation at streaks 7/21/35, seeded opponent teams, streak state persisted by `ZM_SaveSchema`). Shortfalls §1.9 lists what is still unbuilt: the tower SCENE and presentation, the lobby, named tower trainers, the rental flow, the BP/reward shop, the Super/Ultra tiers. This ticket is the SCENE and the RUN; the rental picker and the results/BP presenter are ZM-107.

Scope:
- **Scene:** `BattleTower.zscen` at build index 95 in Zenith Gate (GDD §2.2), kind `TOWER`, an `ZM_InteriorGen` room in two parts: the lobby (receptionist NPC role `ZM_NPC_ROLE_TOWER`, Vesper's standing rematch slot from GDD §3.3 as a trainer row, the door back to Zenith Gate) and the arena approach. Authored by a tools boot under the ZM-D-190 order (a NEW scene, so headless creation is possible only if Zenithmon's Null deferral is lifted for interiors).
- **The run:** talking to the receptionist starts a streak with the player's own party clamped to L50 (`ZM_TowerClampSpec`) or a rental squad (ZM-107); each battle is a trainer battle built from `ZM_BattleTower`'s seeded opponent against the current streak with `m_bCanCatch = false`, `m_bCanFlee = false`; a win advances the streak and returns to the lobby with a continue/retire choice, a loss settles the streak (best streak persisted). Bosses every 7th battle get a named tower trainer row and a speech.
- **Proof:** `ZM_TowerRun_Test`, the *"automated 7-battle tower run"* of the S11 gate: seven wins through the real HUD with `zm_instant_battles`, the boss at battle 7 asserted by name, streak and best-streak read back from a reloaded save, and a loss arm that settles correctly. Headless: the 100-streak simulation invariants of TestPlan §5.10 (rental legality, opponent scaling monotonicity, boss cadence, streak accounting) run over `ZM_BattleTower` directly.
