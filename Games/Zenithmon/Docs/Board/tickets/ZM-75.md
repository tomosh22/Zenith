## Goal
GDD §2.2 interiors 52 and 53: *"Care Center (shared template, instanced per town)"* and *"Trade Post shop (shared template, instanced per town)"*. Every town from Thornacre onward needs both, Dawnmere's are dialogue-only today (the clerk and caretaker stand outdoors), and ZM-71 puts their exteriors into Dawnmere. Build the two interiors ONCE as generated rooms in the `ZM_InteriorGen` idiom ZM-D-220 established for PlayerHome and ProfLab (surface meshes, four-map PBR, lights, furniture from the shipped prop sets, solid colliders per ZM-D-221, `InteriorPropsClearTheEntranceCorridor`), and solve the design problem a shared template raises: a single `.zscen` at build index 52 must return the player to WHICHEVER town's door they entered from.

**The return problem, and the shape to use.** `ZM_WarpTrigger` targets a build index and a spawn tag; a template's exit cannot name one town. Record the origin on the persistent `ZM_GameStateManager` at warp time (the scene id and spawn tag the entering door was authored with; `ZM_ResumePoint` already persists world resume data, so a save inside a Care Center resumes correctly), and have the template's exit trigger resolve `ZM_SCENE_NONE` to "the recorded origin". The WorldSpec rows for 52/53 (ZM-31) therefore carry an EMPTY exit connection and the integrity units get an explicit template exemption with a unit that reds if any OTHER row uses it. A save made inside a template must reload into that template with the origin intact (canned blob if the schema grows; `SaveFormat.md` policy).

**What lives inside.** Care Center: the caretaker (`ZM_NPC_ROLE_CARETAKER`, the existing heal prompt), a PC interactable for the Box screen (ZM-36), Mom's letter pickup hook (a story-flag-gated line, GDD §3.2) for later waves. Trade Post: the clerk (`ZM_NPC_ROLE_SHOPKEEP`) whose stock is a per-town `ZM_ShopStock` row selected by the recorded origin, so later towns sell better balls and TMs without a new scene. Both rooms are authored once by a tools boot (the templates are NEW scenes, so a headless boot may create them if Zenithmon's Null deferral is lifted for interiors; otherwise the ZM-D-190 order).

Thornacre's two doors (ZM-83) are the first consumers and the proof; Dawnmere's follow in ZM-71's exterior placement plus one door each.
