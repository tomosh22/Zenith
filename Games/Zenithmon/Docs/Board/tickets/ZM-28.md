placement header, Fenna's trainer row, the Bloom Badge index and the Verdant Lash

### The placement header is the pattern, not a new idea

Every region has one — `ZM_ProfLabPlacement.h`, `ZM_PlayerHomePlacement.h`,
`ZM_ThornacrePlacement.h`, `ZM_Route1Placement.h`, `ZM_DawnmerePlacement.h`. Add
`Source/World/ZM_Gym1Placement.h` in that idiom: named constants for the maze
walls, the leader's station, the entrance, and the player's arrival point, with
the reasoning in comments the way `ZM_Route1Placement.h` carries its sight-cone
justification.

★ **A GYM INTERIOR HAS NO TERRAIN**, unlike Route 1 and Thornacre. Follow
`ZM_ProfLabPlacement.h` / `ZM_PlayerHomePlacement.h` (interior shells) rather than
the outdoor headers, and do not introduce a terrain set for it.

★ **THE MAZE MUST BE SOLVABLE AND THAT IS A PROPERTY OF THE DATA.** "Puzzle-lite"
is the brief, so keep it short — a few hedge walls with one correct route past
them, not a labyrinth. Prove reachability **in this slice, headless, from the
header alone**: a unit that walks the declared layout and asserts a path exists
from the entrance to the leader's station, and that at least one wall actually
blocks a shorter route (an anti-vacuity arm — a maze with no dead ends is not a
maze, and a reachability test over an empty room passes vacuously).

constant it claimed to police — so it was invariant in the opening width and could red on
nothing. Setting the opening to 11.75 m (half the inner width, three token stubs rather
than a maze) left the whole suite green, because nothing bounded the opening from above.
Confirmed independently by the orchestrator before acting on it. Fixed at fix-forward
attempt 1 of 3: the bound is now `innerMaxX * 0.5` (5.875 m, shell-derived), and the
opening width at which the arm reds (6.275 m) is COMPUTED and asserted from both sides
rather than promised in a comment. Two further instances of the same class were found and
fixed in the same file family. **Unit count unchanged** — content-only — so the 3415 pin
measured before the fix stands, and the verify run re-confirmed it.

Recorded as **ZM-D-212**, because a green gate is not evidence here and the next author
needs to know why.
