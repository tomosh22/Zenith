## Goal
The S9 gate's second clause (`Roadmap.md`, `TestPlan.md` §5.9): *"bake-determinism check: re-running the tools boot produces zero diffs against the existing bake (hash comparison), the generator-determinism invariant at world scale."* Today determinism is proven per family by the generator units (same seed, byte-identical) and per scene by the two-boot rule; nothing proves the WHOLE bake reproduces after every S9 recipe and set has landed.

Scope: a tool-boot mode (`--bake-determinism`) that records a manifest of every file under the game's asset roots (path, size, SHA256) before the bake, runs the full bake and every authoring step with `--skip-unit-tests`, and diffs. Zero diffs is the pass; any diff is reported by path with both hashes. Run it on a warm tree (a cold clone bakes from nothing, which proves regeneration, not determinism, so both runs are recorded). Headless pieces are units: the manifest walker, the diff reporter, and an anti-vacuity arm that reds when a planted byte change is not reported. The windowed run itself is `needs-gpu` (the terrain bake needs a device) and is the gate artefact, recorded in `Docs/Status.md` beside the S9 gate with the file count, byte total and wall time (the ZM-D-054 planning model projected about 25k files and 6 GB for the full region; record the measured figure against it).

Known nondeterminism sources to check first, each already bitten once: `Zenith_ModelComponent::WriteToDataStream` inlining materials (ZM-D-219), computed rotations differing by build configuration (ZM-D-183), physics state reaching scene bytes (ZM-D-179), and generator RNG stream positions consumed conditionally (ZM-D-219 site-fixed jitter).

## Definition of Done
- [ ] A determinism mode records, re-bakes and diffs every asset under the Zenithmon roots and reports zero diffs on a warm S9 tree, with the count, size and time in `Docs/Status.md`
- [ ] The manifest and diff logic are proven headless, including an anti-vacuity arm over a planted change
- [ ] Any diff found is fixed at its source (not excluded) with a `ZM-D-` entry, or the ticket is blocked naming it
- [ ] Every affected game's pinned baseline bumped from an OBSERVED run
