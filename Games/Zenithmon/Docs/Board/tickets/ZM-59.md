## Goal
Shortfalls 1.8-4: the NPC palette does not reach 0.15 RENDERED separation, so townsfolk read as the same person at distance. `Npc_AuthoredAppearancesAreMutuallyDistinct` guards a preview scalar (`ZM_GetHumanPaletteColour`, 0.45 primary + 0.25 accent + 0.30 hair) that reads neither skin, build, attachment nor hair style, so a pair can pass the data check and still merge on screen. ZM-D-171's physically-grounded lighting removed the emissive floor that once masked this, and ZM-D-221 gave humans a four-map PBR set, so the rendered numbers have moved since the audit and must be RE-MEASURED before anything is re-authored.

**Scope:** (1) measure rendered separation per authored pair with a capture test in the pattern of `Tests/ZM_AutoTests_PlayerHomeTintPixels.cpp` (a `requiresGraphics` test that reads back pixels and REPORTS ratios, never asserts a number it picked itself); (2) re-author the outfit primary/accent and hair rows in `Source/Gen/ZM_HumanAppearance.cpp` for the pairs that fail, appending enum values rather than moving existing colours where a committed scene depends on them (save-stable enums, ZM-D-208 ruling 1); (3) reconcile the preview scalar's weights with what the measurement says actually separates people on screen, so the headless invariant stops disagreeing with the pixels.

Interacts with ZM-68 (scene-aware distinctness): this ticket fixes the COLOURS and the measurement; ZM-68 fixes the SCOPE of the invariant. Do the measurement first; if rendered separation is already at or above 0.15 for every pair that can share a frame, the re-author is a no-op and the ticket closes on the recorded numbers.

**Why `needs-gpu`:** a pixel measurement needs a framebuffer, and any re-author of an NPC appearance that is baked into a committed scene follows the ZM-D-190 order.

## Definition of Done
- [ ] A capture test reports rendered separation for every authored NPC pair that can share a frame, and the numbers are recorded in `Shortfalls.md` §1.8-4
- [ ] Every such pair measures at or above 0.15 rendered, after re-authoring only the rows that failed, with no existing scene-bound colour moved
- [ ] The headless preview invariant's weights agree with the measurement, with the derivation recorded in the test
- [ ] Every affected game's pinned baseline bumped from an OBSERVED run
