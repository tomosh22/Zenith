## Goal
Shortfalls §1.9, the Battle Tower presentation ZM-41 leaves out: the **rental squad picker**, the **results and BP presenter**, and the **BP shop**. Scope §1 names *"rental teams"* as in-scope post-game content. `ZM_BattleTower` already generates seeded rental candidates and clamps to L50; what is missing is the UI over it in the S6 `Source/UI/ZM_UI_*` by-value idiom.

Scope:
- **Rental picker:** offered by the receptionist (ZM-41) as an alternative to the player's own party: six seeded candidates shown with species, moves and ability; pick three; the squad is session state on the run and never touches the party or the boxes. Grid on `Zenith_UIGridLayoutGroup`, the S6 navigation rules (no baked links into runtime-hidden pools; windowed tests drive real arrow edges).
- **Results presenter:** after each battle and on settlement, a panel with streak, best streak, BP earned (a new small currency on `ZM_GameState`, a save-schema bump with a canned-blob migration test per `SaveFormat.md`) and the continue/retire choice through the armed-choice idiom.
- **BP shop:** the existing `ZM_UI_Shop` and `ZM_ShopBuy` over a BP-priced stock row (held items and vitamins per GDD §7 item categories), so no new shop code, only a currency selector on the stock row and a purse accessor.

Proof: headless UI-state units for picker legality (three distinct picks, no duplicates, rental never enters the party), BP accounting (per-win award, settlement bonus, purchase deduction, cap), and the schema round trip; `ZM_TowerRun_Test` (ZM-41) gains a rental arm that runs seven battles on a rental squad and buys one item with the BP.

## Definition of Done
- [ ] A rental squad of three can be picked from six seeded candidates and used for a streak without touching the party or boxes, proven headless and windowed
- [ ] BP is awarded, persisted (with a version bump and canned-blob migration test) and spent in the BP shop through the existing shop code
- [ ] The results panel shows streak, best and BP after every battle and on settlement through real focus navigation
- [ ] Every affected game's pinned baseline bumped from an OBSERVED run
