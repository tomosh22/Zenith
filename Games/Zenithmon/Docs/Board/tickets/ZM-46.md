## Goal
`Roadmap.md` S12: *"Save-migration audit; fix backlog"*. `SaveFormat.md`'s binding policy since S7: every schema change is a version bump plus a canned-blob migration test in the same commit, and the blob is FROZEN (ZM-D-223 moved the v2-to-v3 coordinate migration onto `auV2ResumeGolden` because the previous fixture aged a freshly written payload, which proves only that the reader agrees with the writer). `Tests/ZM_Tests_SaveMigration.cpp` has seven units today; by S12 the schema will have moved for the Hall of Fame (ZM-38), BP (ZM-107) and whatever S9/S10 added.

Audit: every version from v1 to the current one has a frozen committed blob; every step migrates forward through the real reader to a state that a fresh writer round-trips byte-identically; every module's byte budget (`ZM_SaveSchema` module table) is asserted; a blob from every S12 segment canned save (ZM-43) loads; a blob with a truncated module and one with a future version fail CLOSED with a named error rather than a crash. Any gap is a fix with its own unit. Then the "fix backlog": every open BUG on the board under ZM-15 and ZM-18 that is not `needs-human` is either Done or carried with a reason, and `Shortfalls.md` §1 sections are reconciled to what shipped.

- [ ] Every schema version has a frozen committed blob and a forward-migration unit through the real reader; module byte budgets are asserted
- [ ] Truncated and future-version blobs fail closed with a named error, proven by units
- [ ] Every segment canned save loads on the current schema
- [ ] Every open non-`needs-human` BUG under ZM-15 and ZM-18 is Done or carried with a reason, and `Shortfalls.md` §1 is reconciled
- [ ] Every affected game's pinned baseline bumped from an OBSERVED run
