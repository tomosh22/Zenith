**I ran it windowed.** ZM-D-177 left this as *"the cause is unattributed — recorded here as deferred work requiring a windowed re-examination"*. That re-examination is done: a fresh `Vulkan_vs2022_Debug_Win64_True` build driven with `--automated-test ZM_InteriorTintPixels_Test --skip-unit-tests` on an RTX 2060.

| | first-run calibration | ZM-D-177 | **today** |
|---|---|---|---|
| PlayerHome red/blue | 1.3045 | 1.1888 | **1.1898** |
| ProfLab red/blue | 1.0742 | 1.0684 | **1.0686** |
| gap (floor 0.15) | 0.2303 | 0.1204 | **0.1212** |

Deltas of ~0.001 against the recorded values — run-to-run noise. **The failure is stable and reproducible, not a flake**, and 266 frames of a 1100-frame budget means nothing timed out.

**It rules out all three causes the test enumerates.** The gap is not ~0, so the tint *did* reach the framebuffer. Both absolutes are not high, so it did *not* leak into ProfLab — ProfLab sits at 1.0686 against a 1.0742 calibration. The gap is not negative, so the bedroom is correctly the warmer room. What remains is that **PlayerHome's tint fell ~0.116 from calibration on its own**: present, correctly signed, too weak.

**Why this is Blocked rather than Done.** The DoD is *"the test passes windowed, or is retired with a recorded reason"*, and neither is available here:

- *Passes* requires strengthening PlayerHome's tint, which re-authors `Assets/Scenes/PlayerHome.zscen`. That is windowed **authoring** — a headless run may CREATE a `.zscen` but never CHANGE one, so the deliverable would be silently missing with every unit green. Filed as **ZM-63**, labelled `windowed`.
- *Retired* is the wrong call and the test says so itself: *"RECORD THAT, do NOT shrink the floor until it passes."* The test is correct, the failure is real, and 0.15 is the ZM-D-176 ruling's threshold rather than a tuning knob. Retiring it — or lowering `fPT_MIN_RATIO_MARGIN` — would buy a green gate by deleting the property under test.

**A note on reachability.** This ticket was nearly declined as unreachable on the reasoning that a `requiresGraphics` test cannot be run headlessly. True of an unattended CI loop; false of a `/tick` on a box with a GPU. `tick.md` step 2 now draws that distinction, because collapsing it declines work that took a 23-second build and one command — and here that work produced the measurement the ticket existed to get.
