# Foundry static visual study

Presentation only. No gameplay component, gameplay update loop, input or save system.
User-requested machine exhaust uses Flux GPU particles. Keep CPU particles disabled.
Foundry.cpp authors the imported workshop, fixed perspective camera and decorative HUD.
The first tools boot imports SourceArt exports and bakes Assets/Scenes/Main.zscen.
SourceArt/generate_workshop.py is the deterministic Blender source; keep the editable blend.
Existing Docs and Mockups are design references and must be preserved.

FOUNDRY_MOCKUP selects Workshop (default), Logistics or MapDefense at process start.
Expanded scenes are generated by SourceArt/generate_expanded_mockups.py using the workshop kit; preserve the approved workshop outputs.

SourceArt/generate_huds.ps1 builds the three original transparent HUD layers with repository Roboto typography. Run it after both model generators and before the tools bake.
