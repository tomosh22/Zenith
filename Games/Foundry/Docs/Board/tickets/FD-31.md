## Goal
GDD §5.1: burner drill (coal-fired, slow) → electric drill; drills output directly onto a belt or into an adjacent machine/container. Drill archetype on the SoA tables: covered patch tiles from the footprint, mining progress in Q16.16 per active tick, output to the facing tile (belt lane placement / container / machine input), fuel via the timer wheel for the burner tier, satisfaction scaling for the electric tier (constant until M1-07 lands). Depletion decrements the patch delta layer; an exhausted drill sleeps and raises the "no ore" status for the inspector.

## Definition of Done
- [ ] A burner drill on iron outputs at exactly the table rate onto a belt (tick-exact pin) and stops when coal runs out (timer-wheel event)
- [ ] Output into a full belt lane blocks without losing progress; output resumes when the lane frees (wake link)
- [ ] Patch depletion persists in the chunk delta layer and survives a serialize/deserialize round trip of the world module
- [ ] A drill placed off-patch is refused with a "needs ore patch" reason code (GDD §6.3)
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
