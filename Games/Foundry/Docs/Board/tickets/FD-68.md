## Goal
TDD §9 and GDD §5.7: pipes and underground pipes union into fluid networks; a network holds `(fluid type, volume, capacity)` and equalizes instantly (the per-network volume model); one fluid type per network enforced at connect time with a clear error; extent capped at ~320 tiles; deterministic split on deconstruction (volume apportioned proportional to capacity, integer division, remainder to the lowest network id). Union-find with the same rebuild-on-remove discipline as electric networks. Phase 7 of the tick order. The M1 `FD_FluidEndpoint` type attaches to a network instead of an adjacent machine.

## Definition of Done
- [ ] Connecting a water pipe to a steam network is refused with the mixing error and mutates nothing
- [ ] Split units: a 2:1 capacity split of 301 units gives 200 / 100 with the remainder to the lower id
- [ ] A 321-tile network is refused at the placement of the 321st pipe with a reason code
- [ ] Conservation: total fluid across all networks is unchanged by any place/remove sequence (fuzz)
- [ ] Golden digest pinned; Foundry pinned baseline bumped from an OBSERVED Null run
