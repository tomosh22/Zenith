## Goal
GDD §5.11 "Defense is structural": walls and gates, gun turrets consuming magazine ammo (the ammo production line is the real defense tech), laser turrets consuming power, machine HP fields. TDD §13: melee/spitter attacks resolve against the occupancy layer and machine HP; turret target acquisition is event-driven — the unit spatial hash publishes cell enter/exit events and turrets subscribe to their range cells, no per-tick range scans. Destroyed buildings are removed as commands (so they appear in the replay log) and refund nothing. Damaged buildings show a status tint.

- [ ] Laser turret damage scales with network satisfaction (brownout halves fire rate — pinned)
- [ ] A wall line of table HP holds a 50-unit group for a pinned number of ticks (digest)
