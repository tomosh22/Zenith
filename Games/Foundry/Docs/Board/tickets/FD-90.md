## Goal
GDD §5.9 and TDD §11: ports project a coverage field; overlapping fields merge into a logistics network; container roles within coverage: Provider, Requester (per-item set-points), Storage (overflow), plus the Core/Depots always providers. Per tick a matcher budget (K requests round-robin per network) pairs requesters with providers — never a full O(requests × providers) scan. `SetRole{handle, role}` / `SetRequest{handle, item, count}` commands with inverses. Phase 9 of the tick order.

- [ ] Coverage union/split on port placement/removal mirrors the electric network discipline (end-of-tick rebuild)
