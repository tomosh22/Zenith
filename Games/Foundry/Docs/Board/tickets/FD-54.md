## Goal
GDD §6.1 control vocabulary and TDD §19 "explicitly game-side": the gesture recognizer is built on `Zenith_Pointers`' verified primitives (8 slots, per-pointer start/excursion/down-time, claims) and publishes through `Zenith_InputActions::PublishVirtualButton/PublishVirtualAxis`. Recognize: pinch (continuous zoom with focus point), two-finger drag (pan), long-press (≥ 350 ms, no excursion), double-tap, two-finger tap (undo accelerator), two-finger tap-hold (rotate in place), and the hold-to-peek variant that cancels on swipe. No gesture with more than two fingers, no shake, no tilt (GDD §6.7). `FD_GestureRecognizer` is a pure state machine over a pointer-event stream so it is unit-testable with synthetic streams and identical on mouse (single pointer) and touch.

## Definition of Done
- [ ] Synthetic-stream units cover every gesture including ambiguity resolution (a pinch that starts as a pan, a long-press that becomes a drag)
- [ ] Pinch zoom keeps the world point under the pinch centroid fixed (unit over the pure math)
- [ ] Two-finger tap emits exactly one undo per tap, never on a two-finger drag
- [ ] Automated Null test `FD_TouchGestures_Test` injects multi-pointer events per the `ZM_AutoTests_TouchControls.cpp` precedent and asserts the camera and command outcomes
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
