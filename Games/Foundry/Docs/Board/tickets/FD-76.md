## Goal
TDD §19 #5: texture export offers Uncompressed/BC1/BC3/BC5 (+BC7 in enums) only (`Tools/Zenith_Tools_TextureExport.h`); no mobile format exists; device suitability never checks `textureCompressionBC` (`Zenith/Vulkan/Zenith_Vulkan.cpp`, `s_bIsPhysicalDeviceHardSuitable`) — a Mali device passes selection and fails at first BC image creation. Add an ASTC (LDR 4×4 / 6×6) export path, format selection per platform at cook driven by the `.ztexdecl` declaration (colour space + compression are declared, never inferred), and the capability check with a clear early failure. Acceptance: Foundry's atlas renders on a Mali device (the device half is verified in M5-09's soak / a device session); BC-only content fails at boot with a named error, not a crash.

- [ ] A Null-config boot with a BC-only texture on a device reporting no `textureCompressionBC` hits the named assertion (simulated via a test hook)
- [ ] Every affected game's pinned baseline bumped from an OBSERVED Null run if the engine suite grew
