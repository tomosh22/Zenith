## Goal
TDD §19 #9: for the Map-tier minimap/pollution overlays, a CPU-writable texture with sub-region upload, sampleable by UI/world quads. Streaming machinery exists internally (terrain chunk uploads); expose a small clean API on the texture asset: `CreateDynamic2D(w, h, format)`, `UpdateRegion(x, y, w, h, pixels)` batched per frame, backend-neutral (Null no-op). Fallback if deferred: the per-chunk instanced-quad map view covers v1, so this is convenience — but it is cheap and it removes 10k quads from the Map tier.
