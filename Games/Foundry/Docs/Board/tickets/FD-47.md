## Goal
GDD §10 and TDD §19 #1: the engine has no audio backend, only the recording bus `Zenith/Core/Zenith_AudioBus.{h,cpp}` — "game code emits through the existing `EmitSound` seam from day one, so all content is authorable before the backend exists." Presentation emits named sounds (`Foundry.Place`, `Foundry.Drill`, `Foundry.Furnace`, `Foundry.Craft`, `Foundry.Research`) from PostTickExtract events for **visible** entities only, with loudness attenuated by camera distance/zoom tier. Sound names are a table in `Source/Content/FD_Sounds.h`. Density-mix policy (aggregate per archetype when > N visible) is designed here as a pure function so M6 only swaps the backend.

- [ ] The density-mix function collapses 200 furnace emissions into ≤ 8 with summed loudness (unit)
