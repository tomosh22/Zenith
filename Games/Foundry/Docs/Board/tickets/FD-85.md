## Goal
GDD §5.8 and TDD §10: rails come from a discrete piece catalog (straight, 45° diagonal, fixed-radius curve) placed via drag — the router auto-chooses pieces along the drag path; junctions form wherever rails meet. The rail graph is exact: nodes at signals/stations/junctions, edges = track blocks with integer lengths in 1/256-tile; visual curves are presentation-only splines. `PlaceRail{pieces...}` as one undo group per drag. The graph rebuilds incrementally on edits and exposes `EdgeLength`, `Neighbours` and a stable edge id for reservations.

## Definition of Done
- [ ] Router units: a drag from A to B with one 90° turn resolves to straights + curve pieces with no gaps or overlaps for every quadrant
- [ ] Two rails crossing form a junction node with four edges; removing one rail dissolves it (unit)
- [ ] Edge lengths are integer-exact and sum correctly around a closed loop (unit)
- [ ] Rail state is a save module with a v1 golden blob
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
