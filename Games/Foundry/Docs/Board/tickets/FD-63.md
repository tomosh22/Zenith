## Goal
GDD §2: Android first, landscape. TDD §17: texture export is BC-only today and BC support is not device-checked, so uncompressed RGBA8 is the M0–M2 stopgap (ZM's approach) — declare it in `Assets/Textures/TextureUsage.ztexdecl` for every Foundry texture. Build `Vulkan_arm64_v8a_vs2022_Debug_Agde_False` and `Vulkan_x86_64_vs2022_Debug_Agde_False`, package assets for the APK per the ZM Android precedent, and boot `FD_Boot_Test` on the x86_64 emulator (the only ABI a machine without an ARM device can run — `adb install` needs `-t`). Record the emulator boot log in the work log; physical-device runs are M2-11.

- [ ] Every Foundry texture is declared uncompressed in `TextureUsage.ztexdecl`
