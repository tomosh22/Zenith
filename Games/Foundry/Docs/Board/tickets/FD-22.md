## Goal
TDD §18: "canned command scripts build factories → run N ticks → FNV-1a over serialized state == pinned digest" as the determinism gate, and "the same runs assert exact deterministic counters" as flake-free perf regression guards — deliberately not wall-clock (the repo shipped a wall-clock CI flake, commit `9bdc28be`). Build `Tests/FD_TestFactory.{h,cpp}`: a small script DSL (`PlaceBelt(run)`, `PlaceInserter`, `PlaceFurnace`, `Feed(item, count)`) producing command sequences; `FD_Sim` emits per-module sub-digests every 64 ticks so a mismatch bisects to (tick, module) (TDD §4 rule 7). Pin three scenarios (belt ring, furnace line, splitter tree) with digests and op-counts as literals. The `FD_Digest` unit family is the pattern every later system ticket extends.

## Definition of Done
- [ ] Three scenarios have pinned final digests and pinned per-tick op-count totals; all pass
- [ ] A deliberately perturbed run (one extra item) reports the first diverging (tick, module) pair
- [ ] Sub-digests are emitted only every 64 ticks and cost nothing in between (op-count of digest calls pinned)
- [ ] `Games/Foundry/Docs/TestPlan.md` documents how to add a scenario and re-pin honestly (re-pin only with a recorded reason)
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
