## Goal
GDD §5.0 — the no-avatar answer. The **Core** is the starting structure, a container that accepts belts/inserters. The **Build Reserve** = Core contents + every Depot flagged build-accessible; placing a building draws its cost from the Reserve instantly, deconstruction refunds it (the fiction is teleported construction material — never a per-placement delivery). The **Core Fabricator** is a slow one-at-a-time crafter inside the Core queuing basic recipes from the Reserve. **Bootstrap:** `HarvestSurface{tile}` commands on rocks/trees yield starter ore/wood → queue a burner drill + stone furnace → place → feed plates back. All as `FD_Command`s with inverses. `PlaceBuilding` is refused with a reason code when the Reserve cannot afford it.

## Definition of Done
- [ ] Placing a building debits the Reserve atomically and a refused placement debits nothing
- [ ] The Reserve sums the Core and Depots and excludes an unflagged container (unit)
- [ ] The Fabricator crafts strictly one recipe at a time at its table rate, via the timer wheel
- [ ] Harvesting a rock yields the table amount, removes the rock from occupancy, and is undoable in principle (inverse command recorded)
- [ ] Golden digest of the bootstrap script (harvest → fabricate → place → feed) pinned; Foundry pinned baseline bumped from an OBSERVED Null run
