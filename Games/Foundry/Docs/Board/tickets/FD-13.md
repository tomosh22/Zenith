## Goal
TDD §6 "The container gap": the engine has no deque, growable ring, slot map or usable pool (`Zenith/Collections/` holds `Zenith_Vector`, `Zenith_HashMap`/`Set`, a compile-time-capacity `Zenith_MemoryPool` and a `Zenith_CircularQueue` that destroys/reconstructs per pop), and `Zenith_Vector`'s default constructor mallocs 8 elements, a policy SimCore's SoA tables must not inherit. Ship under `Source/SimCore/Containers/`:
- `FD_Ring<T>` — power-of-two growable POD ring, no allocation until first push, push/pop both ends, index-from-head, `Reserve`, iteration in head order.
- `FD_SlotMap<T>` — dense storage with per-slot generation, freelist reuse, `u_int32` handles packed as `generation | slot`, generation-checked `Get` returning null for stale handles, index-order iteration over live slots.
- `FD_Bitset` — fixed-or-growable bit array with set/clear/test/`FindFirstSet`, word-aligned.
All three route allocation through `Zenith_MemoryManagement` (L0) and pass the SimCore lint. Unit tests in `Tests/FD_Tests_Containers.cpp` (repo mandate: every new type gets dedicated coverage).

## Definition of Done
- [ ] `FD_Ring` growth preserves element order across a wrap boundary, and a default-constructed ring performs zero allocations (asserted with the allocation counter)
- [ ] `FD_SlotMap` rejects a handle whose slot was freed and reused (generation mismatch), and reuses freed slots LIFO
- [ ] `FD_Bitset::FindFirstSet` is correct at word boundaries and on an all-clear set
- [ ] All three types are POD-only in storage (`static_assert` on `std::is_trivially_copyable`) and pass `Tools/foundry_simcore_lint.ps1`
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
