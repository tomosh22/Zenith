## Goal
GDD §9: low-poly kit-of-parts (drum, hopper, arm, stack), silhouette + colour = identity, tier colourways (Mk1 mustard / Mk2 crimson / Mk3 cobalt), colorblind-safe item icons with shape redundancy. Repo asset policy ignores source GLBs, so the kit must be a **deterministic in-engine generator** baked at tools boot (the `ZM_Gen` precedent: pure library compiled in all configs, disk-bake bridges under `ZENITH_TOOLS`) rather than Blender output: `Source/Gen/FD_KitGen` (parametric part loft → `.zmesh`/`.zmtrl`/`.zmodel`), `FD_IconGen` (icon atlas for the M1 items), `FD_PaletteCheck` (bake-time assertion that no two common items differ by hue alone). Uncompressed RGBA8 textures are the M0–M2 stopgap (TDD §17). Same-seed byte-identical output is the determinism invariant.
