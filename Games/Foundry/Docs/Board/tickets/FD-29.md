## Goal
GDD §4: "Procedurally generated, effectively unbounded. The world is a flat plain streamed in chunks … seed-deterministic." Resources: iron, copper, coal, stone patches; crude oil seeps; water lakes; trees as a pollution buffer; no elevation. TDD §5: patches are generated from the integer hashes at chunk-first-touch and registered in a global patch table; only deltas persist. Implement `FD_WorldGen` over `FD_Noise`: ground type, lakes, tree density, patch placement with richness/distance scaling, the starting-area guarantee (iron/copper/coal/stone/water within reach, oil slightly out — GDD §4), and the world-gen options struct (richness, enemy density, evolution speed, peaceful) threaded through so M2's new-game screen can set them. Patch depletion counters live in the delta layer.

## Definition of Done
- [ ] Same seed + options → identical chunk bytes and patch table (digest-pinned for seeds 1, 0x7BF32CA4 and 0xFFFFFFFF)
- [ ] The starting 5×5 chunk area contains every guaranteed resource for 100 random seeds (unit sweep)
- [ ] Chunk generation touches only its own chunk's RNG state (generating chunks in a different order yields identical bytes)
- [ ] Trees and water tiles are impassable in the occupancy query; oil seeps accept only a pumpjack footprint
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
