## Goal

Designer units are per-second/per-tile; stored units are per-tick Q16.16 via `consteval` helpers so `TICK_RATE` appears once. Ship the schemas and the M1 subset of rows (GDD §5.1–§5.6: ores/plates/steel/brick/gears/cable/circuits, burner+electric drill, stone/steel furnace, assembler Mk1–3, inserter tiers, belt tiers, poles, offshore pump/boiler/steam engine, lab, red science, the ~12 red-tier techs). `u_int8` item ids with the page flag bit reserved (TDD §6). Integrity units: every recipe ingredient/product exists, every tech unlock resolves, every archetype mesh id resolves, no duplicate names, every rate is > 0 per tick after conversion.
