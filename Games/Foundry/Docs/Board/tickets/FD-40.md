## Goal
TDD §2 Shell layer and GDD §6.1/§6.3 with a single pointer (mouse maps onto the touch design, never the reverse). `FD_ShellComponent` (order **102**) reads `Zenith_Pointers` and publishes through `Zenith_InputActions::PublishVirtualButton/PublishVirtualAxis` (zero engine enum changes — TDD §19 game-side list): 1-finger drag = pan; tap entity = select; tap empty in build mode = place at ghost; drag in build mode for linear buildings = lay a run with auto-orient + auto-bend, committed on release; rotate button. Every outcome is an `FD_Command`. Placement validity is live (green/red with a reason line) from a pure `FD_PlacementQuery` over occupancy + Reserve. Multi-touch gestures are M2.

- [ ] A drag-run of 12 belts around a corner produces 12 `PlaceBuilding` commands with correct orientations and one bend (unit over the run resolver)
- [ ] Automated Null test `FD_MousePlace_Test` places a drill on ore through pointer injection and asserts the occupancy handle
- [ ] Tap-select of a stacked target prefers the entity under the pointer (no hover assumptions anywhere)
