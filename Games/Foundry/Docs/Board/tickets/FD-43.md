## Goal
GDD §11: the tech tree is a **vertical tier list** (5 science tiers as sections, techs as cards with prerequisite lines) — not a free-pan node graph. Cards show cost, unlocks and state (locked / available / researching / done); tapping an available card issues `StartResearch` or `QueueResearch`. The research pill in the HUD shows the active tech and progress and opens the tree. Requires the engine `Zenith_UIScrollView`; note that register #8 fixes land in M2 — build against the current API and cover the known hit-test offset defect by keeping the list short enough to fit in M1, recording the dependency in `Docs/Shortfalls.md`.

## Definition of Done
- [ ] Automated Null test `FD_TechTree_Test` opens the tree, starts red-tier automation research and observes the pill progress
- [ ] Prerequisite lines are drawn only between cards in adjacent tiers or within a tier (layout unit)
- [ ] Card state reflects unlock bitset changes within one frame of the research tick
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
