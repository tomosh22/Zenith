## Goal

Shortfalls.md E6, **DEFERRED post-Zenithmon**. Every terrain is a fixed 4096x4096 m grid (`Flux_TerrainConfig::CHUNK_GRID_SIZE` / `CHUNK_SIZE_WORLD` / `TERRAIN_SIZE`) and density is likewise a constant — so a tiny route and a large city are forced to the same world-space size. E2's rect export crops that grid; it does not resize it.

**Keep in mind on every terrain-touching task through the rest of development — do not build content-side workarounds assuming this changes mid-project.**

## Definition of Done

- [ ] Grid constants become per-instance serialized fields
- [ ] Dynamic GPU/CPU buffers in the streaming manager
- [ ] A decoupled density field
- [ ] Engine unit tests + a RenderTest boot regression check + the cross-game sweep
