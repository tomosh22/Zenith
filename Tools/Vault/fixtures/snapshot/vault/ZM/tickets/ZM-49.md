## Goal

Shortfalls.md E8, **DEFERRED, booked 2026-08-01 (ZM-D-173)**. There is no `GetHeightAt(x, z)` of any name on the public surface, so the only way to ask where the ground is, is a physics raycast — which answers a materially different question (*what is the first BODY below this point*) and is not filterable: `RaycastIgnoring` takes exactly ONE ignore entity, restarting below a hit does not rescue it, and it needs the terrain physics body STREAMED IN, so it is unusable at authoring time.

**Two tiers.** TIER 1 serves the query from `GetPhysicsMeshGeometry()` as a triangle lookup — no Jolt, no body filtering. TIER 2 keeps or loads the heightfield and would make the query work at AUTHORING time, retiring the measure-once-freeze-as-a-constant workflow `ZM_DawnmerePlacement.h` is built around.

**Bitten today:** ZM-D-173's Home door jambs sit on the shell's own face, so two solid bodies stand over each jamb's column; their authored heights are derived from ground sampled 0.5 m away and the residual is UNMEASURED.
