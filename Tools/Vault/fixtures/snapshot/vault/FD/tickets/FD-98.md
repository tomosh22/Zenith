## Goal
TDD §13: "Pathfinding is per-GROUP, never per-unit: hierarchical A* over the chunk-level cost graph (chunk cost = base + player-structure density from the occupancy layer), refined to a tile corridor; 1–2 group repaths per tick, hard cap, staggered." The path-provider seam `GetCorridorDirection(group, tile)` is the narrow interface behind which per-corridor cached flow fields can slot in later (M5-06) without touching spawn/combat code. Groups target the polluting region; corridors invalidate when walls are built across them (occupancy edits raise a chunk-dirty flag).
