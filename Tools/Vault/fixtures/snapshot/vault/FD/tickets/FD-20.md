## Goal
TDD §7: "Inserters are event-scheduled, never integrated: a swing is `{eState, uStartTick, uDuration}`; the sim touches an inserter only at transitions (pick, swing-end, place, return-end)." Build the **timer wheel** (`FD_TimerWheel`: buckets keyed by absolute tick, zero cost until due) used by every machine whose next state change is at a known tick, and the inserter archetype on it: three tiers (Inserter ~1 swing/s, Long 2-tile reach, Fast ~2.3 swings/s — GDD §5.3), pick from belts (lane-aware, via binary search over prefix gaps then a bounded splice), machines and containers, place into the same, cached `(line id, offset)` targets invalidated by belt edits through the line graph. Counters: `uInserterTransitions` per tick for op-count pins.

## Definition of Done
- [ ] Timer-wheel units: 10k entries across 4,096 ticks fire in the exact tick they were scheduled for, and an idle wheel performs no per-tick work beyond the bucket advance
- [ ] An inserter polled by the sim only at transitions: over 300 ticks with one swing/s, `uInserterTransitions` is pinned at the exact expected count
- [ ] Picking from the far lane vs near lane is correct for every orientation; a belt edit under a cached target invalidates the cache (no stale splice)
- [ ] Belt↔machine↔container transfers conserve items in a 5k-tick fuzz
- [ ] Golden digest pinned; Foundry pinned baseline bumped from an OBSERVED Null run
