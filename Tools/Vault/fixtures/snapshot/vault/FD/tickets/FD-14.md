## Goal
TDD §4 rules 1–3 and 5–6. Deliver in `Source/SimCore/`:
- `FD_Fixed.h`: Q16.16 fixed point with 64-bit intermediates for mul/div, saturating narrow, `consteval` constructors from designer per-second / per-tile values so `TICK_RATE` is consulted once at table definition (TDD §17). Belt tiers must convert to exactly 16 / 32 / 48 sub-tile units per tick (1/256-tile units, TDD §1).
- `FD_Rng.h`: named `XorShift32` streams (`Zenith/Maths/Zenith_Noise.h` is the engine's one stream-portable PRNG) — worldgen, threat, drones, … — each seeded from the world seed; advancing only inside a tick is the caller's rule, documented.
- `FD_Noise.h`: 2–3 octaves of integer value noise over `HashCoords`/`HashUInt` (bit-exact; the float `ValueNoise`/`FBM` in the same header are banned).
- `FD_Digest.h`: FNV-1a 64 over explicitly little-endian field serialization (never struct memcpy), with a per-module sub-digest accumulator.
Golden vectors are pinned as literals in `Tests/FD_Tests_Determinism.cpp` so a `Null_vs2022_Release_Win64_True` run compares against the same numbers as Debug — the `/Od`-vs-`/O2` canary the TDD names.

## Definition of Done
- [ ] Q16.16 golden vectors (mul, div, narrow, per-second→per-tick) pass, and the three belt speeds convert to 16/32/48 exactly
- [ ] A 1,000-step golden stream per named RNG is pinned and matches
- [ ] The integer noise digest over a 64×64 region is pinned and matches in Debug and in an observed Null Release run recorded in the work log
- [ ] `FD_Digest` over a fixed struct is byte-identical regardless of struct padding (a padded and an unpadded layout yield the same digest)
- [ ] All new headers pass the SimCore lint; Foundry pinned baseline bumped from an OBSERVED Null run
