## Goal
GDD §5.11: pollution is exhaled by drills, furnaces, boilers, assemblers (scaled by activity), spreads chunk-to-chunk, is absorbed by trees and nests, and is visible as a Map-tier overlay. TDD §13: a per-chunk `u_int32` cellular automaton: every 8 ticks, produce (batched per chunk from machine activity), diffuse to 4-neighbours (integer fractions, deterministic order from the sorted chunk list), absorb. Machine pollution rates come from `FD_Archetypes`. Phase 11 of the tick order (threat). GDD §9: renders as an honest desaturating haze on the Map tier.

## Definition of Done
- [ ] Conservation minus absorption: total pollution equals produced − absorbed after N steps (unit)
- [ ] Diffusion is order-independent: chunks created in different orders yield identical fields (digest)
- [ ] The CA runs only on ticks ≡ 0 mod 8 (op-count pinned) and touches only chunks with non-zero pollution or polluting neighbours
- [ ] The overlay chip shows the field through the Map-tier tint source
- [ ] Foundry pinned baseline bumped from an OBSERVED Null run
