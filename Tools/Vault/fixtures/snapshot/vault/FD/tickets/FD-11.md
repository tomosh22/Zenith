## Goal
`Games/Foundry` today is the static visual study (`Foundry.cpp` authors an imported Blender workshop, a fixed camera and a decorative HUD; `Tests/Foundry_Boot.cpp` verifies that model). Its GLB/HUD assets are generated by Blender scripts and gitignored, so on a fresh checkout `zenith test Foundry --headless` reports **zero registered automated tests** and the Foundry category gates are red. Replace the runtime with the skeleton the TDD specifies (TDD §2, §3, §18) so the gates go green without Blender:

- `Foundry.cpp`: the `Project_*` hooks only (`Zenith/Core/Zenith_ProjectHooks.h`). `Project_RegisterGameComponents` registers `FD_GameComponent`; every game component header is `#include`d from `Foundry.cpp` (MSVC dead-strip hazard, `Zenith/EntityComponent/CLAUDE.md`).
- `Components/FD_GameComponent.{h,cpp}` — ECS order **100**, owns exactly two heap pointers `FD_Sim* m_pxSim` and `FD_Presentation* m_pxPresentation` (TDD §2: direct ownership, not pimpl; trivial moves). `OnUpdate` is a stub accumulator that will grow in M0-06.
- `Source/SimCore/FD_Sim.{h,cpp}` with `Tick()` incrementing `m_uTick`, and `Source/SimCore/FD_TickRate.h` — `TICK_RATE = 30` appears in exactly this one header (TDD §1).
- `Source/Presentation/FD_Presentation.{h,cpp}` stub.
- Boot scene (camera + manager entity) authored through `Zenith_EditorAutomation` steps at tools boot and saved to `Assets/Scenes/Main.zscen` (gitignored, fresh-bake policy); headless boots may CREATE a scene.
- `Tests/FD_Tests_Boot.cpp` (`ZENITH_TEST` units: component registered at order 100, `TICK_RATE == 30`, `FD_Sim::Tick` advances) and `Tests/FD_AutoTests_Boot.cpp` (`FD_Boot_Test` automated test on the harness, `--fixed-dt` pinned to 1/30).
- `CLAUDE.md` rewritten to carry the TDD conventions: `FD_` prefix, SimCore is ZenithBase-L0-only (no `g_xEngine`, Flux, ECS, Input, UI, `Zenith_Maths` float types, `float`/`double` in sim state, wall-clock, `std::` containers), command-queue-only mutation, 30 UPS permanently, order space 100/101/102.
- Preserve the design references: `Docs/`, `Mockups/`, `SourceArt/` stay; the study's `README.md` moves to `Docs/VisualStudy.md` and its `TextureUsage.ztexdecl` entries that reference generated textures are dropped.
- `Tools/unit_baselines.json` gains a `"Foundry"` row read from an OBSERVED `Null_vs2022_Debug_Win64_True` run, declared in `advisory` with a reason (no workflow gates it yet — that workflow is a protected-path human task).
