## Goal
TDD §15: the orthographic camera is unreachable and has a latent Y-flip bug, so Foundry ships the steep-pitch **perspective** near-top-down camera CityBuilder proves (`Games/CityBuilder/Source/CB_CameraController.h`, pure-math orbit/zoom controller) reused with pinch/pan sources. GDD §6.2: continuous zoom through three view tiers (Workshop ≲40 tiles across, Logistics ~40–150, Map ≳150) with a fixed steep pitch, no free rotation (4×90° snap is a settings option, default locked), and double-tap quick-toggle between the two most recent zoom levels. `FD_CameraComponent` at ECS order **101** exposes `Pan(dx,dy)`, `Zoom(factor, focus)`, `TierAt(width)` and a tier-changed event Presentation subscribes to.

## Definition of Done
- [ ] Zooming across 40 and 150 tiles emits exactly one tier-changed event per crossing with hysteresis (unit over the pure controller)
- [ ] Pan is world-plane exact: a pan by N tiles at any zoom moves the focus by N tiles (unit)
- [ ] Quick-toggle returns to the previous zoom level and back (unit)
- [ ] Orientation snap is off by default and, when enabled, snaps only to multiples of 90°
