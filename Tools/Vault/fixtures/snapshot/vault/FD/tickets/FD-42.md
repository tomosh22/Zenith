## Goal
GDD §6.4 — the no-hover answer. Tap any entity → Inspector docks to the short edge (right on landscape): identity, recipe/filters (tap to edit via the searchable, category-tabbed recipe picker), contents, throughput sparkline (from the stats rings), power satisfaction, context actions (rotate · copy settings · deconstruct · disable). The factory stays live beside it. Hold-to-peek: press-and-hold ≥ 350 ms without release → transient info card at the reticle; release without lifting into a swipe = no selection change. The Inspector explains alerts ("no power: network 2 at 40%"). The recipe picker is shared with the Core Fabricator.
