## Goal
TDD §12 and GDD §5.10: red/green wires union into circuit networks; a network's value set is a sorted vector of `(u_int16 signal, int32 count)`; readers sum contributions; double-buffered so evaluation reads the previous tick's published values and writes the back buffer, swapped at phase 12 — the fixed 1-tick delay that makes order irrelevant. Hooks: containers (read contents), belts (read contents / hold), inserters (enable/disable, set filter), pumps (enable), power switch, lamps, machines (read / enable). `ConnectWire{a, b, colour}` with inverse. Wires are limited by pole reach like Factorio's (poles carry wires).

## Definition of Done
- [ ] Order-independence unit: the same network evaluated with combinator/reader order permuted yields identical values every tick
- [ ] A container-fed "enable inserter when iron < 500" condition toggles on exactly the tick after the count crosses (1-tick delay pinned)
- [ ] Removing a wire splits the network at end of tick and both halves publish independently
- [ ] Circuit state is part of the world digest and the save module
